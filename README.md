# FoR MZ. · FORME MUSIC V4（手稿改版）

按照手绘参考重新设计：**首页为纵向编号的文件夹列表，进入后是 01、02、03… 编号曲目列表**，纯黑白韩系画册风格。

## 保留已有文件和排序

这次沿用原版的 IndexedDB 数据库 `forme-local-v3`（版本 `1`），没有迁移或删除数据库。

- 歌曲依然根据 MP3 **原文件名中的数字**优先升序排列：01、02、03、10、11、100。
- 没有数字的歌按中文/字母自然排序；列表的 `01/02/03` 只表示显示位置，不参与排序。
- 已导入的歌曲、文件夹、收藏均可继续使用，前提是**同一网站网址、同一 iPhone 浏览器/PWA 存储空间**。
- 顺序播放会取消随机模式；用户仍可在播放器里自行选择随机播放。

## iPhone 部署（GitHub Pages）

1. 解压 ZIP，将其中所有网页文件上传至**现有 GitHub Pages 仓库的同一路径**并覆盖旧文件，不要直接上传 ZIP。
2. 在 Safari 重新打开网页，若使用主屏幕 PWA，彻底关闭再重开以获取更新。
3. 打开文件夹 → 「导入歌曲」，从 iPhone「文件」中选择 MP3；导入后自动按数字优先排序。

⚠️ 不要删除 Safari 网站数据或卸载原有主屏幕 App 来强制更新；这些动作可能删除你已导入的本地歌曲。不要改变仓库网址。iOS 仍可能清除网站存储，请保留 MP3 原文件。系统媒体卡片、灵动岛和后台播放受 iOS 限制。
